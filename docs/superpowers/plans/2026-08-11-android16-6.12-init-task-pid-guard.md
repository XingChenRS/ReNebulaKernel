# Android 16 / 6.12 `init_task` PID Guard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preserve KernelSU-family `SET_INIT_PGRP` semantics while preventing the two confirmed Android 16 / 6.12 PID0 pointer panic paths.

**Architecture:** The provider adapter will target the canonical PID0 `init_struct_pid` symbol directly. A separate family-scoped kernel adapter will harden the two RCU PID readers for `init_task`, record provenance, and remain a no-op for LKM and non-6.12 variants.

**Tech Stack:** Python 3 standard library, `unittest`, Linux C source rewriting with exact anchors, GitHub Actions YAML, schema-5 ReNebula build plans.

## Global Constraints

- Apply the core guard only when `family_id == "android16-6.12"` and the variant artifact is `image`.
- Preserve the `SET_INIT_PGRP` ioctl and its PID0-process-group semantics.
- Do not change SUSFS, KPM, Vivo vermagic, uname, source locks, or public workflow inputs.
- Reject source drift before writing any modified source file.
- Preserve the user's untracked `.artifact-audit-20260811/` directory and `temp.gz`.
- Verification build: `android16-6.12-lts-2026-08-03`, `resukisu`, SUSFS on, KPM off, Vivo vermagic off, empty uname tag.

- [ ] **Step 4: Implement the exact-anchor C adapter**

Insert after `task_pid_ptr()`:

```c
static struct pid *renebula_task_pid_read(struct task_struct *task,
                                         enum pid_type type)
{
    struct pid *pid = rcu_dereference(*task_pid_ptr(task, type));

    if (unlikely(task == &init_task && pid != &init_struct_pid)) {
        pr_warn_once("ReNebula: repaired corrupted init_task PID reference\n");
        return &init_struct_pid;
    }
    return pid;
}
```

Replace exactly these two expressions and reject any unexpected counts before writing:

```c

nr = pid_nr_ns(renebula_task_pid_read(task, type), ns);
```

Use one final `write_text(..., newline="\n")` only after every anchor has been validated.
